O que falta para sair do protótipo

Roadmap técnico

1. Backend / proxy

As chamadas à API do NúcleoGov exigem sessão (cookie) e cabeçalhos específicos — não dá pra chamar direto do navegador do visitante (CORS). Precisa de um backend que já faz isso e serve os dados prontos ao site.

2. Completar os módulos restantes

9 módulos ainda sem endpoint confirmado (despesas, dispensas, terceirizados, estagiários) — mesmo processo de engenharia reversa, módulo a módulo.

3. Cron jobs

Agendar sincronizações periódicas (folha quinzenal, contratos mensais) como já existe em Piracanjuba.

4. Banco de dados multi-tenant

Parametrizar por município para este protótipo virar uma instância real da plataforma, não um site solto.
